# [4 Superhabits of a Superproductive Person](https://sites.google.com/view/paperstackpro/home)

No apps. No subscriptions. Just paper.

## 1. Daily Time-Blocking → Yearfolio
Undated daily pages, hourly slots from 6:00–22:00. Log the day as it happen.

## 2. Weekly Reset → Weekly Planner Notebook
ISO week numbering gives you the whole week at a glance. One look, one page.

## 3. One Idea, One Card → Index Card Notebook
160 cards, 8 sections, Zettelkasten-ready numbering. Brainstorms, code sketches, 2×2s, daily reflections.

## 4. Handwritten notes  → INK
Handwrite first — memory and creativity work better with pen on paper.

**The pattern:** _Create handwritten notes (INK) → log daily (Yearfolio) → plan weekly (Weekly Planner) → file neatly (Index Card Notebook). Four habits, four notebooks, zero friction._
