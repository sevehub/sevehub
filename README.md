## 0. [AI Work Log](https://a.co/d/06l4mRno): the hub

Every AI chat gets one page in the AI Work Log. 


<img src="diagram.svg" alt="Superhabits of Superproductive Professionals Flowchart" width="100%">


| Step | Notebook | Action |
|------|----------|--------|
| 1 | INK | Handwrite the question or draft before opening the chat |
| 2 | AI Work Log | Record the chat on one page: prompt, hypothesis, findings |
| 3 | Yearfolio | Note the page number in the time block where the chat took place |
| 4 | Weekly Planner | Tally the week's chats under the ISO week number |
| 5 | Index Card Notebook | Promote each confirmed finding to one card, with the log page as reference |

---

## 1. Daily Time-Blocking → [Yearfolio](https://a.co/d/06N61UUO)
Undated daily pages, hourly slots from 6:00–22:00. Log the day as it happens.

## 2. Weekly Reset → [Weekly Planner Notebook](https://a.co/d/0j6QAOvg)
ISO week numbering gives the whole week at a glance. One look, one page.

## 3. One Idea, One Card → [Index Card Notebook](https://a.co/d/0ftEvPyW)
160 cards, 8 sections, Zettelkasten-ready numbering. Brainstorms, code sketches, 2×2s, daily reflections.

## 4. Handwritten Notes → [INK] (https://a.co/d/0iFN0AYl)
Elevate your field notes by prioritizing handwriting to maximize memory and creativity, while integrating a vast, free digital library for on-demand reference.
